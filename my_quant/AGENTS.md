本仓库的量化研究与课程实验默认使用中文输出。任何策略结论都必须先和明确基准比较，再讨论是否存在 Alpha。

## Baseline: 中国永久组合

默认基准为“中国永久组合”，用于衡量本仓库后续策略是否真的值得研究。

| 资产 | AkShare / 场内 ETF 代理 | 权重 |
| --- | --- | ---: |
| 中国股票 | `510300` 沪深300ETF | 25% |
| 中国长期利率债 | `511260` 10年国债ETF | 25% |
| 黄金 | `518880` 黄金ETF | 25% |
| 现金 / 货币 | `511880` 银华日利ETF | 25% |

回测口径：

- 数据源：AkShare `fund_etf_hist_sina`
- 区间：`2021-01-04` 至 `2026-06-15`
- 价格：日收盘价
- 再平衡：每年第一交易日恢复到 25% / 25% / 25% / 25%
- 成本：未计交易费、滑点和税费
- 复权限制：该口径为价格序列，债券 ETF 与货币 ETF 的真实总收益可能被低估

基准结果：

| 指标 | 数值 |
| --- | ---: |
| 累计收益率 | 32.09% |
| 年化收益率 | 5.25% |
| 年化波动率 | 6.67% |
| 最大回撤 | -8.94% |

后续策略默认至少要超过 `5.25%` 年化收益率，才算在收益层面跑赢基准。更严格的判断还要同时看最大回撤、夏普比、卡玛比、索提诺比、逐年收益和样本外表现。

## Strategy Evaluation Rules

- 不要只报告累计收益；必须同时报告年化收益率、年化波动率、最大回撤和至少一个风险调整指标。
- 不要只和沪深300比较；除非任务另有说明，默认同时和中国永久组合比较。
- 如果策略靠更高股票仓位、更高海外权益仓位或更高换手率跑赢，需要明确说明多赚的钱来自更高风险、分散化、择时、因子，还是参数过拟合。
- 策略只有在样本外、Walk-Forward 或参数敏感性分析中仍能稳定跑赢 `5.25%` 年化时，才可以暂时称为候选策略。
- 历史收益不是投资建议；所有结论只用于课程研究和回测学习。
