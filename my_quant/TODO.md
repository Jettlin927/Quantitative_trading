# TODO: 如何尝试超过中国永久组合基准

当前基准：中国永久组合年化收益率 `5.25%`，最大回撤 `-8.94%`。后续研究的核心问题不是“能不能把回测调高”，而是能不能在样本外稳定超过这个年化门槛，并且回撤没有失控。

## 1. 先把基准纳入所有回测

- [ ] 在 q5 的“基准与风险调整指标”实验中加入中国永久组合，作为沪深300买入持有之外的第二基准。
- [ ] 所有策略表格新增“相对永久组合超额年化收益”列。
- [ ] 验收标准：策略年化收益率 > `5.25%`，并报告相对基准的超额收益、最大回撤差异、卡玛比差异。

## 2. 用分散化提高收益来源，而不是只押 A 股

仓库 q2 已经强调：分散风险的关键不是多买几个，而是买涨跌不同步的。永久组合能赢沪深300，主要靠黄金和国债在 A 股弱势时接住组合。

- [ ] 在投资宇宙中保留 `510300`、`518880`、`511260`、`511880`，并加入课程已有的 `513100` 纳指100ETF作为增长资产候选。
- [ ] 扩展低相关资产池：红利 ETF、宽基小盘 ETF、可转债 ETF、商品 ETF、港股科技 ETF，先做相关性矩阵和单资产风险收益表。
- [ ] 验收标准：新增资产不是因为“涨得多”才加入，而是要证明它和现有资产低相关，且能改善组合的年化收益 / 回撤比。

## 3. 替换静态 25% 权重：风险平价优先

永久组合的优点是简单，缺点是 25% 权重不等于 25% 风险贡献。仓库 q3 已经有 RiskParityOptimizer 的训练路径，可以先做风险平价版永久组合。

- [ ] 用 `RollingVolatility` 计算各资产 20 日或 60 日波动率。
- [ ] 跑 `EqualWeight` vs `RiskParity` vs 永久组合原始 25% 权重。
- [ ] 验收标准：风险平价版本的年化收益率超过 `5.25%`，最大回撤不明显高于 `-8.94%`。

## 4. 用风险调整动量做“进攻/防守切换”

仓库 q3 的 TopNRanking 思路是：涨得好的多买，跌的不买。超过永久组合最现实的路径，是在趋势明确时减少现金和弱资产权重，在趋势转弱时退回债券、黄金或货币。

- [ ] 对每个资产计算 20/60/120 日动量和风险调整动量 `RAM = momentum / volatility`。
- [ ] 用 `TopNRankingOptimizer(score_col="ram", filter_negative=True)` 测试 Top 1、Top 2、Top 3。
- [ ] 当所有风险资产 RAM 为负时，允许组合切到 `511880` 或短债。
- [ ] 验收标准：动量策略年化收益率超过 `5.25%`，并且不是靠单一年份暴涨贡献全部超额。

## 5. 控制交易频率和成本

仓库 q4 已经说明交易不是免费的。动态策略想超过永久组合，必须确认超额收益能覆盖手续费、滑点和调仓摩擦。

- [ ] 扫描每周、双周、月度、季度调仓频率。
- [ ] 加入交易成本和滑点假设，至少测试 `0.1%` 单边成本。
- [ ] 验收标准：含成本后仍超过 `5.25%` 年化；如果无成本跑赢、含成本跑输，策略不合格。

## 6. 增加止损或趋势过滤，但不要把低位当入场信号

永久组合最大回撤约 `-8.94%`，这个回撤门槛很低。想超过它，不能只追求收益，还要避免 A 股或海外权益大跌时把组合拖进深回撤。

- [ ] 测试 `StopLossRule`：5%、10%、15% 三档。
- [ ] 测试均线趋势过滤：价格低于 120 日或 200 日均线时降低权益仓位。
- [ ] 明确纪律：低位不是入场信号，止跌才是入场信号。
- [ ] 验收标准：止损/趋势过滤能改善卡玛比，而不是只降低收益。

## 7. 做参数敏感性，不接受“魔法参数”

仓库 q6 的重点是防止过拟合。超过 5.25% 很容易，稳定超过才难。

- [ ] 扫描动量窗口：20、60、120、180 日。
- [ ] 扫描波动率窗口：20、60、120 日。
- [ ] 扫描调仓频率：10、21、42、63 个交易日。
- [ ] 验收标准：存在一片参数高原，而不是只有一个参数点跑赢。

## 8. 做样本外和 Walk-Forward 验证

如果策略只在 2021-2026 这段黄金大牛市里跑赢，可能只是吃到了黄金趋势，不一定有未来价值。

- [ ] 样本内：2017-2020；样本外：2021-2026。
- [ ] 或者使用 Rolling / Anchored Walk-Forward，每 6 个月验证一次。
- [ ] 验收标准：样本外年化收益率仍超过 `5.25%`，且每折参数不要剧烈跳变。

## 9. 做因子诊断：先证明信号真的有预测力

仓库 q9 的动量 IC 分析提醒：单一动量因子整体预测力可能接近 0。要超过永久组合，不能只相信净值曲线，还要看信号是否有横截面预测能力。

- [ ] 对候选资产池计算动量、风险调整动量、低波动、趋势强度等因子的 IC。
- [ ] 分高波动和低波动市场状态分别看 IC。
- [ ] 验收标准：至少一个因子在低波动或特定市场状态下有稳定正 IC，否则不要用它驱动仓位。

## 10. 最可能跑赢的候选路线

优先级最高的实验路线：

1. 投资宇宙：`510300`、`513100`、`518880`、`511260`、`511880`。
2. 权重方法：风险调整动量 Top 2，过滤负 RAM。
3. 防守资产：无正动量时切到 `511880`，或在黄金 / 国债中选 RAM 更高者。
4. 调仓频率：月度起步，避免过度交易。
5. 验证方式：先和中国永久组合比年化收益，再比最大回撤和卡玛比，最后做 Walk-Forward。

这条路线有可能超过 `5.25%` 的原因：它保留永久组合的多资产防守底盘，但在趋势明确时把 25% 现金和弱势资产的机会成本降下来，让组合更集中地吃到黄金、海外权益或债券趋势。
