# 09 默认最终候选：RAM Top2 月度切换

## TODO 对应

- TODO 10：最可能跑赢的候选路线。

## 策略假设

最有希望超过永久组合的路线，是保留多资产防守底盘，同时在趋势明确时把资金集中给更强的资产。Top2 比 Top1 更分散，比 Top3 更能减少弱资产拖累。

## 执行流程

1. 投资宇宙使用 `510300`、`513100`、`518880`、`511260`、`511880`。
2. 进攻资产为 `510300`、`513100`、`518880`、`511260`。
3. 默认从 60 日动量 / 60 日波动率起步，作为 TODO 第 10 节的直观版本。
4. 运行参数扫描后，当前轻量初筛候选改为 20 日动量 / 120 日波动率。
5. 计算 `RAM = momentum / volatility`。
6. 过滤 RAM 小于等于 0 的资产。
7. 选择 RAM 最高的 Top2。
8. 按 RAM 比例分配 Top2 权重。
9. 如果没有正 RAM 资产，100% 切到 `511880`。
10. 每 21 个交易日调仓。
11. 加入 `0.1%` 单边成本。
12. 与永久组合比较年化收益、最大回撤和卡玛比。
13. 再进入参数敏感性、样本外和因子诊断。

## 通过条件

- 年化收益超过永久组合。
- 卡玛比高于永久组合。
- 最大回撤没有失控。
- 参数敏感性中 Top2 附近有稳定高原。
- 样本外仍超过永久组合。

## 淘汰条件

- 只在 2021-2026 的黄金或纳指趋势中有效。
- 参数扫描显示 Top2 只是孤立最优。
- 样本外回撤明显失控。
- 因子 IC 无法支持 RAM 信号。

## 对比输出

- RAM Top2 指标表。
- RAM Top1 / Top2 / Top3 对比。
- 月度 / 双月 / 季度调仓对比。
- 训练期最优参数样本外表现。
