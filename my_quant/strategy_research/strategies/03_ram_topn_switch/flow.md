# 03 RAM TopN 进攻/防守切换

## 策略假设

永久组合稳，但现金和弱势资产在趋势市场里会拖累收益。RAM TopN 只持有风险调整动量为正的强势资产；当风险资产全弱时，切回防守资产。

## 执行流程

1. 投资宇宙使用 `510300`、`513100`、`518880`、`511260`、`511880`。
2. 风险资产集合使用 `510300`、`513100`、`518880`、`511260`。
3. 对每个风险资产计算动量：`price_today / price_n_days_ago - 1`。
4. 对每个风险资产计算波动率：最近 `n` 日收益标准差。
5. 计算 `RAM = momentum / volatility`。
6. 过滤 RAM 小于等于 0 的资产。
7. 测试 Top1、Top2、Top3。
8. 被选资产按 RAM 比例归一化分配权重。
9. 如果没有风险资产 RAM 为正，切到 `511880`。
10. 月度调仓起步，含 `0.1%` 单边成本。

## 通过条件

- 年化收益超过中国永久组合。
- 超额收益不是由单一年份贡献。
- 卡玛比高于中国永久组合。
- TopN 选择在参数敏感性中有高原，而不是只有一个最优点。

## 淘汰条件

- Top1 或 TopN 只靠单一资产暴涨取胜。
- 含成本后跑输永久组合。
- 样本外或 Walk-Forward 参数剧烈跳变。

## 对比输出

- Top1 / Top2 / Top3 指标表。
- 权重历史图，允许出现 100% 防守资产。
- 与风险平价、永久组合的净值曲线。
