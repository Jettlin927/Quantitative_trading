# A 股数据沙盘

本目录记录 Docker PostgreSQL 中 A 股数据底座的覆盖审计、同步命令和数据质量结论。真实数据仍保存在 Docker volume `postgres_data` 中，不复制到 Git。

## 当前职责

- 证明 `stock_daily_bars` 和 `stock_daily_basic` 是否覆盖最终验收要求的过去 5 年。
- 记录 Tushare 同步命令、同步区间、行数、失败日期和只读 SQL 验证结果。
- 标注数据缺口、延迟和仍未完成的财务指标覆盖。

## 当前覆盖结论

截至 `2026-06-26 19:36 +08:00` 的只读审计，Docker DB 中：

- `stock_daily_bars` 覆盖 `2021-06-28` 到 `2026-05-29`，共 `6,155,284` 行、`5,713` 个标的、`1,192` 个交易日。
- `stock_daily_basic` 覆盖 `2021-06-28` 到 `2026-05-29`，共 `6,134,626` 行、`5,713` 个标的、`1,192` 个交易日。

这满足“Docker 中的 DB 有过去 5 年 A 股日线和 daily_basic 数据”的当前验收口径。由于 A 股交易日原因，`2021-06-26` 是周末，实际首个交易日为 `2021-06-28`。
