# 美股优先工作台与旧数据链路退役

状态：已接受（2026-08-05）

## 背景

产品已经从多市场数据浏览和实验脚本集合转向美股个人投研工作台。继续同时维护 A 股同步、免费美股实验、旧 sample/HSBC ledger 和个人不可变记录，会让 API、前端、运维角色和研究资格边界继续漂移，并把历史兼容误写成当前产品能力。

## 决策

- 产品与运行时以美股为主。当前主线是用户手工维护的持仓、规则与 AI 分析，Alpaca 市场观察，以及与个人工作台隔离的正式研究治理。
- 退役 A 股产品页面、Tushare 数据拉取、公共同步 Worker、A 股策略执行入口和对应定时任务。
- 退役只展示既有 A 股策略档案的研究驾驶舱前端与 `/research` 产品路由；历史发布数据和通用正式研究治理后端继续保留用于审计与未来美股研究，不再作为当前产品页面暴露。
- 退役 `us_experiment_*` 的 AKShare/yfinance 免费实验运行时、旧 `my_quant` sample 与 HSBC ledger，以及对应 API、页面和定时任务。
- 退役个人工作台的不可变记录版本链路。持仓、规则、分析草稿、分析运行和 synthetic trace 继续保留；正式研究的不可覆盖发布合同继续保留。
- 观察规则作为活跃持仓的后台确定性检查继续保留，由私有 Worker 周期评估并把最新异常投影到今日工作台；独立 `/rules` 页面和一级导航退役，历史规则、评估与 API 兼容边界不删除。
- 不改写或删除既有 Alembic revision。历史表、自然键和模型兼容可继续用于迁移验证与 schema-only 测试，但不得恢复为活动 API、同步任务、前端入口或研究资格。
- 历史研究工件、已发布评价、dated 审计和迁移清单继续作为证据保存。引用已删除路径的历史文档应标注退役时间和替代入口，不伪装成当前操作手册。

## 当前运行边界

- 公共 Compose 默认只需要 PostgreSQL、API 与前端；正式研究 Worker 继续受独立 profile 和人工批准约束。
- 个人分析 Worker 只通过私有 Compose 覆盖启用，并保持私有 schema、secret 与正式研究隔离。
- 本地和 CI 可只建立完整 schema 并插入合成夹具，不需要 Tushare、AKShare、yfinance 或真实 A 股数据。
- 生产部署、production migration、生产表删除、volume 清理和凭据变更仍需针对精确操作另行授权。本决策本身不授权任何生产变更。

## 取代关系

- 本决策取代 ADR 0007 中“个人研究记录”作为当前工作台对象的部分；ADR 0007 的私有 schema、加密、安全入口和正式研究隔离原则继续有效。
- 本决策更新 ADR 0008 的当前生产服务口径：公共数据 Worker 已退出目标拓扑；ADR 0008 关于单一生产服务器和旧服务器退役的决定不变。
- ADR 0004 的“正式研究发布不可覆盖”与本次退役的“个人不可变记录版本”不是同一对象，前者不受影响。

## 后果

代码、前端、Compose、运维文档和 GitHub 路线图应围绕同一条美股主线收敛。历史 schema 会暂时宽于当前运行时，这是有意的迁移兼容边界；未来若要物理删除旧表，必须新增前向 Alembic revision、独立数据保留方案和生产授权，不能在本轮结构整改中顺手执行。
