# 个人投资工作台不再包含研究系统

状态：已接受（2026-08-06）

## 背景

产品主线已收敛为美股个人投资工作台。继续把旧量化研究治理、执行、评价和发布能力
写成当前产品，会误导 Agent、用户和运维流程，并让遗留代码看起来仍受支持。

## 决策

- 当前产品只包含手工持仓与成交事实、Alpaca 市场观察、确定性规则提醒、个人 AI
  分析和系统健康检查。
- 项目不再提供量化研究计划、策略运行、回测、评价、发布、研究 Worker 或研究页面。
- 旧研究代码、脚本、配置、schema、工件和文档统一视为遗留兼容或历史审计资产，
  不作为新任务入口，不继续扩展，也不接入当前产品拓扑。
- 本决定不授权删除遗留代码、表、工件或文档。物理清理必须先分类调用方、迁移历史、
  API、测试、生产数据与外部依赖，再由独立 Issue 和明确授权执行。

## 取代关系

本决策取代 ADR 0010 中“正式研究治理继续作为后端基础设施”的部分。ADR 0001 至
0004、0006 以及 ADR 0007 中的正式研究隔离条款仅作为历史设计证据保留，不再描述
当前产品。ADR 0005、0008 的生产安全边界和 ADR 0009 的个人 AI 分析决定继续有效。

## 后果

- `AGENTS.md`、`CONTEXT.md` 和默认文档导航只描述个人投资工作台。
- 当前架构文档可指出遗留研究资产的存在，但不再展开其工作流程或把它列为受支持能力。
- 后续清理按“入口、调用方、API/UI、测试、migration、历史工件、生产数据、外部调用”
  逐项证明可移除；文件名、目录名或日期不能单独作为删除依据。
