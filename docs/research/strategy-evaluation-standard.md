# 策略画像与评价规范

状态：仓库强制规范 1.0

适用范围：本仓库内任何新策略的研究、分析、评估、回测、横向比较和阶段性复核

## 目的与边界

本规范把“一个策略是否足够好”拆成可验证的策略画像、数据证据、执行证据、不同市场环境表现、风险、稳健性和可复现性。后续交付不得只展示累计收益、年化收益或 Sharpe，也不得用单一总分替代证据。

默认对象是日频、离线、股票和 ETF 研究。分钟/Tick、高频、期权、做市或其他非线性策略必须先声明本规范中哪些项目不适用，并增加该资产所需的订单簿、延迟、Greeks、波动率曲面或尾部风险指标；不能静默省略。

本规范不改变交易边界。`研究通过` 只表示当前研究证据满足预先声明的门禁，不构成投资建议、买卖评级、收益承诺、生产发布或真实交易授权。

## 强制结论状态

每份策略报告开头必须且只能使用下列一种状态：

| 状态 | 含义 |
| --- | --- |
| `研究通过` | 全部硬门禁通过，样本外、风险、成本、市场环境和稳健性达到事前门槛；仍然只是研究结论。 |
| `有条件候选` | 数据和协议可信，但部分市场环境、容量或软门槛存在明确限制，只能在列明条件下继续观察。 |
| `证据不足` | 没有足够样本外长度、独立调仓/交易次数或市场环境覆盖，无法判断总体好坏。 |
| `blocked` | 缺关键 point-in-time 数据、基准、可交易性、成本、执行账本或复现证据，研究不能继续下结论。 |
| `不通过` | 证据充分且协议可信，但策略未达到事前收益、风险、稳健性或容量门槛。 |

不得把 `blocked`、`证据不足` 或管线测试成功写成 `研究通过`。baseline/sentinel 证明研究管线可以工作，不等于证明策略具有 alpha。

## 硬门禁

下列任一关键门禁不满足时，不得评价为“好策略”或 `研究通过`：

1. **身份与假设**：有稳定的 `strategy_id + strategy_version`、经济假设、适用对象和明确失效机制。
2. **时点与宇宙**：使用 point-in-time 数据和历史成员；不存在未来函数、当前成分回填或幸存者偏差。
3. **执行语义**：信号时点、首次可成交时点、价格口径、停牌、涨跌停和缺价处理明确且可审计。
4. **成本与流动性**：收益为扣除费用、税费、滑点和适用冲击成本后的净收益；高换手策略必须给出成本压力测试。
5. **基准**：基准与资产、地区、币种和风险目标相匹配，并使用同频率总收益口径。
6. **样本外**：正式判断只使用未参与参数选择的 test/OOS；训练区间不得混入最终指标。
7. **市场环境**：至少报告方向、波动率和逐年/压力期拆分；样本不覆盖时必须标记 `证据不足`。
8. **试验历史**：记录候选策略、参数组合和筛选次数；多次试验不能只保留冠军。
9. **风险与容量**：最大回撤、尾部风险、集中度、换手、成交阻塞和预期资金规模下的流动性有明确结论。
10. **可复现**：绑定数据快照、代码提交、标准化配置、随机种子、产物哈希和 `result_fingerprint`，并可离线 reproduce。

## 标准交付顺序

未来研究任何策略时，报告必须按以下顺序交付，不能把结论藏在长篇过程之后：

1. 结论卡：强制状态、最重要依据、最大风险、适用和失效环境。
2. 策略画像：身份、经济假设、目标、基准、宇宙、信号、组合和风控。
3. 数据证据：日期、频率、point-in-time、历史成员、缺失项和质量门禁。
4. 执行与成本：信号到成交、不可成交、费用、滑点、冲击和容量假设。
5. 样本外总体指标：策略、基准、主动收益、风险、交易和集中度。
6. 市场环境拆分：方向、波动率、流动性、年份和预先声明的压力期。
7. 稳健性与过拟合：walk-forward、参数邻域、成本压力、试验次数、DSR/PBO（适用时）。
8. 风险与容量：回撤、ES、暴露、风险贡献、参与率和容量。
9. 限制与下一步：缺失证据、不能支持的结论和下一次最小验证。
10. 复现身份：配置、数据快照、代码提交、运行 ID、可复现键和结果指纹。

## 策略画像

策略画像至少包含下列字段：

| 模块 | 必填内容 |
| --- | --- |
| 身份 | 策略名称、`strategy_id`、版本、研究状态、研究日期。 |
| 经济假设 | 收益来源、可能承担的风险、谁是潜在交易对手、为什么规律可能持续。 |
| 目标与基准 | 绝对/相对收益目标、风险预算、基准、无风险利率、预设验收门槛。 |
| 资产与宇宙 | 市场、资产类别、历史成员来源、上市/退市、流动性和排除规则。 |
| 数据与时点 | 输入字段、频率、`observed_at/available_from`、复权、公告和修订口径。 |
| 信号 | 完整公式、方向、窗口、warmup、缺失值和并列排名处理。 |
| 组合构建 | 选择数量、权重、现金、单票/行业限制、再平衡和换手限制。 |
| 执行 | `signal_date`、`execution_date`、参考价格、不可成交和部分成交处理。 |
| 成本 | 佣金、税费、滑点、冲击模型、成本压力倍数和毛/净收益口径。 |
| 风控 | 最大权重、行业暴露、gross/net、回撤、止用条件和容量。 |
| 验证设计 | IS/validation/OOS、walk-forward、试验次数、参数冻结和市场环境定义。 |
| 失效机制 | 可能失效的市场结构、拥挤、流动性、政策或数据变化。 |

## 数据证据

报告必须列出实际使用的数据，而不是只列“理论上需要”：

| 数据组 | 最低要求 | 缺失时的结论 |
| --- | --- | --- |
| 行情与总收益 | 原始 OHLCV、复权因子、分红拆股、上市/退市、交易日历。 | 复权、退市或日历缺失时 `blocked`。 |
| 历史宇宙 | 逐日/逐期指数或行业成员、有效期、来源哈希。 | 用当前成员替代历史成员时 `blocked`。 |
| 可交易性 | 停复牌、涨跌停、开盘价、成交额、最小交易单位。 | 无法判断真实成交时 `blocked`。 |
| 基本面 | 报告期、公告时间、修订版本和最早可得日。 | 严格财务研究缺修订历史时 `blocked`。 |
| 基准与因子 | 同币种总收益基准、无风险利率、需要时的风格因子。 | 无匹配基准时不得报告主动能力。 |
| 执行与成本 | 调仓请求、模拟成交、未成交、持仓、费用、滑点或可验证代理。 | 只能报告毛收益时不得 `研究通过`。 |
| 研究身份 | quality run、snapshot、代码、配置、随机种子、试验登记。 | 无法复现时 `blocked`。 |

每份报告必须同时写明：样本起止日、warmup、总观察数、开市日数、调仓次数、请求/成交/阻塞次数、独立交易数和各市场环境的样本数。日收益条数不能替代独立决策次数。

## 市场环境拆分

市场环境必须在查看策略分组表现之前定义，只能使用基准或全市场数据，不得按策略收益反推最有利的分组。

最低拆分要求：

1. **方向**：上涨、下跌、震荡；阈值和观察窗口必须事前写明。
2. **波动率**：高波动、低波动；分位点必须来自训练/参考期，不得用最终 OOS 重新调阈值。
3. **流动性**：数据可得时按全市场或策略宇宙成交额/ADV分组。
4. **日历**：逐年结果，避免一两个年份掩盖长期失效。
5. **压力期**：仅使用事前声明或客观事件区间，不得事后挑选有利区间。
6. **策略专项**：行业、大小盘、风格或利率环境只在经济假设相关时增加。

每个环境单元至少报告：日期范围、观察数、调仓/交易数、策略净收益、基准收益、主动收益、年化波动（样本允许时）、最大回撤、换手、成本、阻塞率和期末/平均暴露。样本不足时指标写 `not_available` 并给出原因，不能填 0。

一条策略如果总收益很好，但主要利润只来自单一环境，必须写成 `有条件候选` 或 `证据不足`，不能写成跨环境稳定。

## 强制图表

形成正式 Markdown、HTML 或 PDF 研究报告时，至少包含：

1. 策略净值与基准总收益净值对比。
2. 策略回撤曲线，并标注最大回撤和最长未恢复区间。
3. 逐年收益表或热力图，以及方向 x 波动率市场环境矩阵。
4. 换手/成本曲线；组合策略再增加 gross/net、现金和集中度曲线。

图表必须来自同一份 canonical 指标和账本产物，不能重新使用另一套口径计算。聊天内的初步小结可以用等价数据表代替图表，但不得省略基准、回撤或市场环境证据。

## 指标字典

统一记号：\(r_t\) 为扣除全部成本后的策略周期收益，\(b_t\) 为基准总收益，\(f_t\) 为无风险收益，\(V_t\) 为净值，\(A\) 为年化周期数（日频通常为 252），\(T\) 为观察数。所有正式指标默认使用 test/OOS。

### 必报收益与风险指标

| 指标 | 统一计算 | 解释 |
| --- | --- | --- |
| 累计净收益 | \(\prod_{t=1}^{T}(1+r_t)-1\) | 整段财富变化；必须与毛收益和成本拖累区分。 |
| CAGR | \((V_T/V_0)^{A/T}-1\) | 长期复合增长；不足一年只报累计收益，不把年化值作为结论。 |
| 年化波动 | \(sd(r_t)\sqrt A\) | 总波动；有显著自相关时必须说明并使用自相关稳健口径。 |
| Sharpe | \(\overline{r_t-f_t}/sd(r_t-f_t)\times\sqrt A\) | 每单位总风险的超额收益；不得单独决定策略好坏。 |
| 下行波动 | 令 \(d_t=\min(r_t-MAR_t,0)\)，计算 \(\sqrt{\overline{d_t^2}}\sqrt A\) | 只衡量低于最低可接受收益的波动。 |
| Sortino | \(\overline{r_t-MAR_t}/\sqrt{\overline{d_t^2}}\times\sqrt A\) | 每单位下行风险的超额收益。 |
| 最大回撤 | \(\max_t(1-V_t/\max_{s\le t}V_s)\) | 最坏峰谷亏损。 |
| 最大回撤持续期 | 从前高跌落到恢复前高的最长周期；未恢复则计至样本末日 | 资金被套和策略失效持续时间。 |
| Calmar | \(CAGR/MDD\) | 每单位最大回撤的复合增长；MDD为0时 `not_applicable`。 |
| 偏度 | \(E[((r-\mu)/\sigma)^3]\) | 识别平时小赚、偶尔大亏等不对称结构。 |
| 超额峰度 | \(E[((r-\mu)/\sigma)^4]-3\) | 识别厚尾和极端事件频率。 |
| VaR | 对损失 \(L=-r\)，\(VaR_q=Q_q(L)\) | 给定置信度的损失阈值。 |
| Expected Shortfall | \(ES_q=E[L\mid L\ge VaR_q]\) | 越过VaR后的平均尾部损失。 |

### 必报基准、组合和交易指标

| 指标 | 统一计算 | 解释 |
| --- | --- | --- |
| 基准累计收益 | \(\prod(1+b_t)-1\) | 同期可比基准的财富变化。 |
| 相对财富 | \(\prod(1+r_t)/\prod(1+b_t)-1\) | 策略最终财富相对基准的变化。 |
| Tracking Error | \(sd(r_t-b_t)\sqrt A\) | 主动风险。 |
| Information Ratio | \(\overline{r_t-b_t}/sd(r_t-b_t)\times\sqrt A\) | 每单位主动风险的主动收益。 |
| Alpha/Beta | 回归 \(r_t-f_t=\alpha+\beta(b_t-f_t)+\epsilon_t\)；需要时扩展多因子 | 区分市场暴露和剩余主动收益。 |
| Gross/Net Exposure | \(\sum_i\lvert w_i\rvert\) / \(\sum_i w_i\) | 总风险敞口、杠杆和方向性。 |
| 最大权重 | \(\max_i\lvert w_i\rvert\) | 单一资产集中风险。 |
| HHI/有效持仓数 | \(HHI=\sum_iw_i^2\)，\(N_{eff}=1/HHI\) | 组合集中度。 |
| 组合波动 | \(\sigma_p=\sqrt{w^T\Sigma w}\) | 考虑相关性的总体风险。 |
| 总风险贡献 | \(TRC_i=w_i(\Sigma w)_i/\sigma_p\) | 每个资产贡献的风险；总和应等于组合波动。 |
| 单边换手 | 默认 \(0.5\sum_i\lvert w_i^{after}-w_i^{before}\rvert\)；若实现采用其他口径必须显式写明 | 成本和容量压力。 |
| 成本拖累 | 毛累计收益减净累计收益，并分解费用、税费、滑点和冲击 | 判断纸面 alpha 被成本消耗多少。 |
| 成交/阻塞率 | 实际成交金额/请求金额；阻塞金额/请求金额 | 评估停牌、涨跌停和流动性影响。 |
| ADV参与率 | 订单金额/同期ADV，报告中位数、P95和最大值 | 评估计划资金规模的容量。 |

离散交易策略还必须报告胜率、平均盈利、平均亏损、盈亏比、单笔期望和 Profit Factor；无法稳定定义一笔交易边界的组合策略不得强行生成这些指标。

## 稳健性与过拟合证据

至少报告：

1. **OOS总体结果**：只由未参与选择的数据构成。
2. **walk-forward**：逐窗口列出训练/测试边界、OOS指标、通过率、中位数和最差窗口。
3. **参数邻域**：相邻合理参数是否平滑；只在单点有效视为高风险。
4. **成本压力**：至少比较基准成本和预先声明的更高成本情景。
5. **环境稳定性**：收益是否集中在少数年份、单一方向或单一波动率环境。
6. **统计不确定性**：报告样本数和适当的置信区间；有自相关时使用HAC等稳健标准误。
7. **试验登记**：列出候选数量和选择过程。

若发生参数搜索、多策略筛选或反复查看 OOS，必须增加：

- **Deflated Sharpe Ratio（DSR）**：以样本长度、偏度、峰度、候选 Sharpe 分布和独立试验数修正冠军 Sharpe。
- **PBO**：通过组合对称交叉验证，统计训练期冠军在对应样本外落到候选中位数以下的比例。

没有参数搜索且身份、参数在数据查看前已固定的 baseline，可将 DSR/PBO 标为 `not_applicable`，但必须说明试验次数为1及固定证据。

## 结论门禁

所有验收阈值必须在查看最终 OOS 前写入策略配置或研究计划。仓库不设“Sharpe大于某个固定值就算好策略”的通用魔法数字。

`研究通过` 至少要求：

- quality/snapshot/执行/复现硬门禁全部通过。
- OOS净收益、主动收益和风险指标达到事前门槛。
- 最大回撤、ES、集中度和容量不超过风险预算。
- 多个市场环境有足够样本，结论不由单一窗口或少数交易支配。
- 参数邻域、成本压力和walk-forward没有出现与总体结论相反的系统性崩塌。
- 多次试验时，DSR/PBO达到事前置信与过拟合预算。

不得把指标加权成一个不透明总分。最终结论必须列出“支持证据”“反对证据”“尚缺证据”三栏，让用户可以独立判断。

## 缺失值语义

报告和机器产物统一区分：

- `not_applicable`：指标对该策略无定义，并说明原因。
- `not_available`：理论适用，但当前样本或数据不足。
- `blocked`：缺失直接破坏可信研究，不能继续下结论。

不得把上述任一状态替换为0、空字符串或“表现一般”。
