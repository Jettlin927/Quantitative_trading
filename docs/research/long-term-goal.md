# 长期策略目标与阶段推进规则

本文件定义本项目的长期北极星目标，以及每个阶段如何推进、验收和新建下一阶段文件夹。

## 终极目标

终极目标不是当前策略已经接近的目标，而是长期研究方向：

- 年化收益率 `>= 100%`。
- 最大回撤绝对值 `< 10%`。
- 已完成交易盈亏比 `>= 3:1`。

说明：这里的“回测在 10% 以下”按最大回撤绝对值 `< 10%` 处理。收益必须扣除交易成本、滑点和现实成交压力；如果未来纳入纸面交易或实盘前验证，还要同时看执行偏差。

## 当前状态

当前主线 `cross-section-strength-risk8` 仍是观察级候选，不是候选、合格研究级或纸面交易策略。

当前证据：

- `105` 三年全窗口年化 `12.89%`、最大回撤 `-6.72%`、盈亏比 `2.62:1`。
- 新近阶段目标年化 `30%` 未通过。
- `106/110` 滚动窗口只通过 `3/7`。
- `107/108/109/111/112/113` 已证明继续放松高开、振幅、市场宽度或成交量单一权重不是简单解。

因此下一步不是硬调参数冲收益，而是先解释失败窗口为什么没有正期望。

## 文件夹推进规则

阶段目录位于 `docs/research/stages/<stage-id>/`。

每个阶段目录至少包含：

- `README.md`：阶段目标、假设、成功标准、失败条件。
- `evidence.md`：阶段内关键证据、引用的 run id、失败样本和结论。
- `next-stage.md`：只有阶段验收通过后才创建，用来说明为什么进入下一阶段。

推进规则：

1. 当前阶段未验收前，只在当前阶段目录内追加证据，不新建更高阶段目录。
2. 当前阶段验收通过后，先写 `next-stage.md`，再新建下一个阶段目录。
3. 新阶段的第一个文件必须是 `README.md`，并写清楚新阶段目标、数据窗口、硬门槛和不得再重复尝试的负证据。
4. 若阶段失败，保留阶段目录，状态写为 `blocked` 或 `retired`，不能删除失败证据。
5. 若修改收益、回撤、盈亏比或成交语义，必须说明历史结果是否仍可比较。

## 当前活跃阶段

当前活跃阶段为 `001-observation-diagnosis`。

本阶段最重要的问题：

为什么 `105` 在完整三年窗口可看，但在 `Y1/Y2/R18-1/R18-2` 中没有稳定正期望？

本阶段默认不做：

- 不继续微调止损和止盈。
- 不继续单独放宽高开、振幅或市场宽度闸门。
- 不为了冲收益扩大仓位或取消现实成交压力。

本阶段优先做：

- 失败窗口 vs 通过窗口的行业暴露差异。
- 买入候选 `entryScoreParts` 分布。
- 盈利交易和亏损交易的评分组成差异。
- 被风险过滤器挡掉的票，事后表现如何。
- 当前排序因子到底是在选强票，还是只在特定行情里碰巧有效。
