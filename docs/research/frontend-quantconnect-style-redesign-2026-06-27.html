前端 QuantConnect 式数据呈现重构报告

结论标签：观察

本次前端已从深色卡片式驾驶舱改为更接近 QuantConnect 策略页的信息结构；只调整展示，不改变后端策略评估语义。

参考方向

参考页的核心是研究终端式的数据密度：标题、作者、版本、关键指标、权益/回撤/基准/容量图表、概览表和滚动统计表。

  • 左侧导航和顶部黑色工具栏模拟研究平台信息架构。
  • 指标横条展示累计收益、Sharpe、盈亏比、最大回撤、年化收益和闭环交易。
  • 图表网格展示策略权益、资产销售量、回撤、基准和容量。
  • 右栏展示作者、三段验证闸门、硬门槛、研究 run 和证据文件。

语义边界

  • 仍读取后端统一评估接口，不在前端手填策略结论。
  • 不新增回测按钮，不提交回测参数。
  • 三段窗口仍由后端判定；旧策略全部 legacy_reset 后，页面展示 新策略研究台，正式两段等待新策略证据。
  • Sharpe、Sortino、盈亏比按普通数值展示，不格式化成百分比。
