# 纸面交易与运行准备计划

本计划只定义研究结果如何落地为每日纸面作业，不连接真实券商、不自动下单、不处理真实资金。

## 纸面交易作业单

每日收盘后生成一张作业单，字段至少包括：

- `signalDate`：信号日。
- `tradeDate`：计划执行日，默认次一交易日。
- `tsCode`、`name`、`industry`。
- `entryScore` 和 `entryScoreParts`。
- `plannedBuyPrice`、`stopLossPrice`、`takeProfit1Price`、`takeProfit2Price`。
- `targetPositionPct`、`riskPct`、`plannedShares`、`lotAdjustedShares`。
- `invalidIf`：失效条件，例如市场宽度转弱、次日开盘跳空、涨跌停无法成交、数据缺失。
- `riskFlags`：高开、振幅、下影线、停牌、ST、上市不足、流动性异常等。
- `manualDecision`：人工接受、跳过、降仓或备注。

## 纸面订单与成交账本

作业单之后维护独立账本：

- `paperOrders`：计划订单、触发条件、是否触发、是否因涨停/跌停/停牌/价格偏离取消。
- `paperFills`：纸面成交价、数量、滑点、手续费、成交原因。
- `paperPositions`：独立持仓，不复用回测内部状态。
- `paperInterventions`：人工干预原因和时间。
- `paperReconciliation`：每日对账，比较纸面执行和回测假设的差异。

## 数据质量报告

每日运行前先生成数据质量报告，至少检查：

- 日线覆盖率：候选池、市场宽度池、实际信号池的日期和标的覆盖。
- 停牌、ST、退市、上市不足 `N` 天处理是否一致。
- 涨停/跌停状态是否能由价格限制规则或权威字段确认。
- 复权规则是否统一。
- 财务数据若进入因子，必须按公告日 point-in-time 使用。
- 缺失数据是否会改变入池样本、排序或市场宽度判断。

## 运行时风控

纸面交易阶段先实现运行时暂停条件：

- 当天纸面最大亏损超过阈值，暂停新开仓。
- 连续亏损达到阈值，暂停新开仓并生成复盘。
- 数据覆盖率、行情日期或市场宽度样本异常，暂停新开仓。
- 实际纸面成交偏离回测假设超过阈值，暂停并复核滑点/涨跌停模型。
- 策略近期表现偏离历史分布，自动降级为观察并停止扩大仓位。
- 每日和每周生成风险报告，列出触发原因、未触发但接近阈值的项目、人工干预。

## 进入纸面交易前置条件

`105` 目前不满足进入纸面交易条件。至少需要先完成：

- 失败窗口归因报告。
- 排序因子消融报告。
- 数据质量报告原型。
- 纸面作业单、订单、成交、持仓、对账的最小数据结构。
- 运行时风控暂停规则。
