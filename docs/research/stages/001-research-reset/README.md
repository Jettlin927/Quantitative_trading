# 001-research-reset

## 阶段状态

`active`

## 阶段目标

旧策略全部从主线退场后，从零开始建立新的策略研究流程。

本阶段不追求先跑出高收益曲线，而是先固定：

- 数据源和字段白名单。
- 新策略假设模板。
- 三段评估窗口执行口径。
- 失败条件和禁止重复路线。
- 新旧证据隔离方式。

## 当前硬门槛

本阶段不以收益达标为验收。先满足以下工程与研究门槛：

- 旧策略不再出现在前端主策略位。
- 后端 `/api/research/dashboard` 的 `baseline` 为 `null`。
- `/api/strategy-evaluations` 不返回旧策略评估项。
- `docs/research/strategy-lifecycle.json` 中旧策略全部为 `legacy_reset`。
- 新策略必须先写假设，再允许进入回测。

## 禁止事项

- 不把旧 Risk8、B1、RAM、Kronos 改个名字继续当新策略。
- 不从历史结果里挑漂亮片段反推策略。
- 不直接物理删除旧证据文件。
- 不绕过 2020-2024、2025-当前、熊市观察三段评估。
- 不接入真实券商、真实持仓或真实交易执行。

## 下一步

新策略从以下材料开始：

1. 数据字段：先确认 A 股和美股各自可稳定落库的字段。
2. 市场假设：写清楚赚的是趋势、反转、质量、风险退潮规避还是资金拥挤。
3. 评估口径：先确定指标，再写回测。
4. 负证据隔离：旧结果只能作为“不要重复”的提醒，不作为候选策略输入。
