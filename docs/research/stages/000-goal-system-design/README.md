# 000-goal-system-design

## 阶段目标

把用户确认的长期目标固化为仓库内可执行的研究推进制度：

- 终极目标：年化收益率 `>= 100%`。
- 最大回撤绝对值 `< 10%`。
- 已完成交易盈亏比 `>= 3:1`。
- 每达成一个阶段目标后，新建下一个阶段目录继续推进。
