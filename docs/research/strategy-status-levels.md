# 策略状态分级

本文件用于避免“文件名像可执行、结论却未合格”的心理误导。策略状态按证据推进，不按命名或主观偏好推进。

## 分级

| 状态 | 含义 | 晋级要求 |
| --- | --- | --- |
| 淘汰 | 已有证据显示该路径不能同时满足收益、回撤、尾部或稳健性要求。 | 不晋级；只作为负证据保留。 |
| 观察 | 有局部价值，但核心目标或稳健性未过。 | 找到失败窗口归因，并证明下一轮修复不是偶然调参。 |
| 候选 | 全窗口达到当前目标，且主要风险解释清楚。 | 通过滚动窗口、消融、参数敏感性和尾部审计。 |
| 合格研究级 | 全窗口、滚动窗口和主要稳健性验证均过，且实验台账可复现。 | 建立纸面交易作业流和对账机制。 |
| 纸面交易 | 每日生成候选、订单计划和独立持仓账本，但不接真实账户。 | 累积足够纸面交易样本，成交偏差与回测假设可解释。 |
| 实盘前验证 | 纸面交易表现稳定，运行时风控、数据质量和人工复核流程完整。 | 用户明确确认真实交易边界、资金、券商和权限。 |
| 实盘 | 连接真实交易账户并承担资金风险。 | 本仓库默认禁止自动进入；必须另行确认。 |
