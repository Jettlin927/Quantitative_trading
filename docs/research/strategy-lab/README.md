# 策略思想库

`strategy-lab/` 用来保存交易纪律、规则卡片、验证口径和负证据。这里不是回测结果目录，也不是实盘指令目录；它回答的是“这个规则为什么存在、准备用什么 A 股样本验证、什么时候算失败、能否谨慎映射到美股持仓报告”。

## 写规则卡片的最低要求

每条规则至少包含：

- 规则一句话。
- 为什么存在。
- A 股验证口径。
- 成功标准。
- 失败条件。
- 美股映射边界。
- 当前证据状态。

## 使用边界

- A 股验证只能支持通用交易纪律，不能证明某个美股单票一定赚钱。
- 没有完成 A 股验证前，规则只能作为报告中的“待验证纪律”引用。
- 任何动作标签都是研究辅助，不是买入、卖出、持有或收益承诺。
