用户已确认新增持久化 DB schema。本阶段已创建美股 sample 数据表、sample 导入 API 和 DB 只读 overview，并已把 sample 数据写入本地 PostgreSQL。

POST /api/us-research/import-sample 返回 dbPersistence=sample_persisted，总计 upsert 13 行规范化 sample 记录。

API

  • GET /api/us-research/import-preview：只读 preview，显示 dbSchema=ready。
  • POST /api/us-research/import-sample：只导入 my_quant/us_research/ sample 文件。
  • GET /api/us-research/db-overview：从 DB 返回 db-sample overview。
  • GET /api/us-research/overview 和 GET /api/research/dashboard：优先使用 DB sample。
