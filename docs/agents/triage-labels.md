# 分诊标签

技能内部使用五个固定分诊角色；本文件把它们映射为本仓库实际使用的中文 GitHub 标签。

| 技能内部角色 | GitHub 中文标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `待分诊` | 等待维护者判断 |
| `needs-info` | `待补充信息` | 等待报告者补充 |
| `ready-for-agent` | `可由智能体处理` | 信息完整，可由智能体自动执行 |
| `ready-for-human` | `需人工处理` | 必须由人参与处理 |
| `wontfix` | `不予处理` | 明确不进入实施 |

后续新增标签默认使用中文。若外部技能引用英文角色，必须先查本表并转换，不能直接创建英文标签。

## GitHub 默认标签中文化

| 原默认标签 | 当前中文标签 |
| --- | --- |
| `bug` | `缺陷` |
| `documentation` | `文档` |
| `duplicate` | `重复` |
| `enhancement` | `功能` |
| `good first issue` | `新手友好` |
| `help wanted` | `需要帮助` |
| `invalid` | `无效` |
| `question` | `问题` |
| `wontfix` | 已删除，统一使用 `不予处理` |

不要重新创建已清理的英文标签。
