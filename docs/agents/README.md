# Agent 工作参考

根 [AGENTS.md](../../AGENTS.md) 保存每次任务都要遵守的规则。本目录只保存命中对应
任务时读取的分支参考：

- 创建、领取、更新或关闭 Issue：[Issue tracker 与 Wayfinder](issue-tracker.md)
- 修改领域术语或架构决定：[领域文档](domain.md)
- 创建或转换标签：[分诊标签](triage-labels.md)
- 选择检查范围并报告验证结果：[变更验证](validation.md)

完成条件：本目录的规则不得复制根安全门禁，也不得缓存当前 Issue、分支、提交、CI
或生产状态。
