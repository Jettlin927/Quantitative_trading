# 领域文档

本仓库采用 single-context：`CONTEXT.md` 是统一领域语言，`docs/adr/` 保存系统级、
难以逆转的决定。

## 修改流程

1. 完整读取 `CONTEXT.md` 和与目标有关的 ADR。
2. 判断问题是既有术语被误用，还是确有新的领域概念或系统决定。
3. 语言漂移时统一 Issue、规格、测试和代码用词；新领域概念写入 `CONTEXT.md`；系统
   决定写入新 ADR，并显式说明与既有 ADR 的关系。
4. 搜索受影响术语，确认每个修改点使用同一含义，且没有静默覆盖现有决定。

只有讨论真正解决了术语或决定时才新增内容；缺少结论时记录问题，不预先编造模型。
