# 产品范围

本模块保存稳定的产品边界、用户旅程和研究驾驶舱说明，不保存运行 ID、生产提交、表行数或短期任务状态。

## 核心旅程

1. 查看实际市场数据的来源、覆盖和质量边界。
2. 阅读策略档案与冻结研究计划。
3. 由授权用户按精确计划哈希批准正式研究。
4. 查看研究运行事实、证据、评价、强制结论、限制与后续提案。
5. 从只读前端或 Issue 回到同一评价版本和证据身份。

## 界面边界

- 一级区域为研究驾驶舱、A 股数据、美股数据和系统运维。
- 实际市场数据、sample、运行状态、研究结论和系统健康必须显著区分。
- 原始 HTML 是证据入口，不是唯一产品界面。
- 不提供实盘、账户、下单、买卖评级或收益承诺入口。

统一术语见 [CONTEXT.md](../../CONTEXT.md)，活动产品任务见 [第一阶段实施总览](https://github.com/Jettlin927/Quantitative_trading/issues/17)。
