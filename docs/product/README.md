# 产品范围

本模块保存稳定的产品边界与用户旅程，不保存运行 ID、生产提交、表行数或短期任务状态。

## 核心旅程

1. 在今日工作台查看手工美股持仓、确定性规则和数据缺口。
2. 在美股标的页核对 Alpaca 来源、时点和证据资格。
3. 创建并显式确认与正式研究隔离的个人 AI 分析。

## 界面边界

- 一级区域为今日、持仓、美股市场、规则和系统健康。
- 实际市场数据、合成夹具、个人上下文、运行状态、研究结论和系统健康必须显著区分。
- 原始 HTML 是证据入口，不是唯一产品界面。
- 不提供实盘、账户、下单、买卖评级或收益承诺入口。

不提供 A 股、旧美股实验、个人不可变记录或旧策略驾驶舱入口。正式研究的历史发布与治理合同仅作为后端审计基础设施保留。统一术语见 [CONTEXT.md](../../CONTEXT.md)，当前整改路线图见 [Issue #214](https://github.com/Jettlin927/Quantitative_trading/issues/214)。
