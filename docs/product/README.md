# 产品范围

当前产品是单用户、美股优先的个人投资工作台。它帮助用户维护事实、查看市场证据、
接收确定性提醒并发起 AI 分析；不连接账户、不执行交易，也不包含量化研究系统。

## 核心旅程

1. 在今日工作台查看活跃持仓的注意事项、规则命中和数据缺口。
2. 在持仓页手工维护持仓、现金、买卖事实并查看权益历史。
3. 在美股标的页核对 Alpaca 行情的来源、时点和可用性。
4. 创建分析草稿，检查外发预览，显式确认后由私有 Worker 执行 AI 分析。
5. 在系统页查看来源授权、schema 和服务健康。

## 界面边界

- 一级区域只有今日、持仓、美股市场和系统健康；规则异常汇入今日页。
- 实际行情、个人事实、合成夹具、运行状态和系统健康显著区分。
- 缺失、过期或未授权数据展示明确状态，不伪造成零值或最新事实。
- 不提供 A 股、研究、回测、策略驾驶舱、实盘、账户、下单、评级或收益承诺入口。
